# Micro Racers

A tiny Micro Machines-style top-down racer in a single HTML file. No dependencies, works offline.

**Play:** open `index.html` in any browser.

- **Drive:** Arrow keys or WASD
- **Handbrake (drift):** Space
- **Restart:** R · **Pause:** P
- Touch controls appear automatically on phones/tablets.

Race 3 laps against three AI toy cars on a kitchen table. Fall too far off the road and the hand of god puts you back. Best time is saved locally.
