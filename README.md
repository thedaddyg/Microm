# Micro Racers

A tiny Micro Machines-style top-down racer in a single HTML file. No dependencies, works offline.

**Play online:** https://thedaddyg.github.io/Microm/ — or just open `index.html` in any browser.

- **Drive:** Arrow keys or WASD
- **Handbrake (drift):** Space
- **Restart:** R · **Track menu:** N · **Pause:** P · **Difficulty:** D
- Touch controls appear automatically on phones/tablets.

Race 3 laps against three AI toy cars (Easy / Medium / Hard). Fall too far off the road and the hand of god puts you back. Best times are saved locally per track.

## Tracks

1. **Kitchen Table** — asphalt circuit between coins, a pencil and coffee stains.
2. **Mini Golf** — ramp jump over a water carry, sand traps, an infield pond, and a windmill that bats cars aside.
3. **Backyard Machine** — a Rube Goldberg contraption: drive over the pressure pad to topple dominoes, which tip a seesaw, which launches a bowling ball across the track, which splashes into the kiddie pool, which turns on the sprinkler and soaks a corner. Also featuring a garden-hose bump, a sandbox, a flower bed, and a sleeping dog.

Pushes to the dev branch auto-deploy to GitHub Pages via `.github/workflows/pages.yml`.
